## 4. 반복해서 나온 고장 — 종류별

### 가드가 알리바이였던 방식 (이번 주에만 여덟 번)

- **소스를 셌다** — 분량·개수는 렌더 결과로. 가이드는 보간으로 목록을 뿌린다
- **렌더를 안 봤다** — 425개 테스트가 통과하는 동안 본문 71곳이 별표를 화면에 내보냈다
- **렌더는 봤는데 엔티티를 안 풀었다** — `&gt;`가 남아 로컬은 초록, 라이브는 빨강
- **`toContain`이 위치를 안 봤다** — 같은 값이 다른 문단에 있으면 표를 손으로 적어도 통과
- **손으로 적은 대조 목록** — 버터 80g→800g이 통과했다(배치·개당이 같이 커진다). 목록을 정의에서 만들 것
- **문자열 금지** — `not.toContain("$2.03")`이 정당한 값에 오탐. 금지할 것은 문자열이 아니라 **의미**
- **문법 열거** — "기울임이 렌더되나" 대신 "원문 기호가 남으면 실패"로 걸었더니 고장 4개가 더 나왔다
- **우연한 통과** — 상품도 factor도 틀렸는데 곱해져 "두 배"를 만족시켰다. 둘 다 고치니 문구가 거짓

### 데이터가 조용히 틀어지는 방식

- **크론이 상품을 다시 고른다** — 한 번 실행에 **28개**가 바뀌었다(`Peas`→완두칩, `Rocket`→치즈파이). 고정만이 답
- **이름은 맞고 물건이 다르다** — 코코넛오일=스프레이, 옥수수=크림콘, 토르티야=타코용 소형
- **이름 필터는 라벨을 못 본다** — 견과 경고 붙은 뮤즐리가 `Muesli (Nut-free)`로 들어와 있었다
- **아무도 안 보는 필드가 가장 조용히 낡는다** — 이미지 26/43이 빈 채로 몇 달
- **파생값도 선 가정이 틀리면 더 틀린다** — factor는 팩 크기 위에 얹힌다

### 문구가 사실과 갈라지는 방식

- **같은 일을 하는 자리가 둘 이상** — 주간 표가 **세 곳**(가이드·블로그 둘)에 각각 다른 값으로 있었다
- **퍼센트의 분모가 다르다** — 5개 총액과 12개 총액을 견줘 "73%"
- **없는 권장량을 지어낸다** — 탄수화물·지방은 NRV에 RDI·AI·UL이 **없다**
- **살 수 없는 것을 재료명으로** — 넛프리 뮤즐리·완제품 차슈·민트 처트니는 NZ 매대에 없다
- **자리표시자가 화면으로** — 가격지수 표가 "TBD" 9칸을 독자에게 보이고 있었다
- **연락처가 둘** — 방침 페이지 한 화면이 브랜드 주소와 개인 주소를 같이 말했다

## 5. 🔴 내가 저지른 실수 — 반복하지 말 것

1. **순진한 가격 필터를 두 번 썼다.** `isComparableRow`(신선도 게이트)를 빼먹어 격차 14%(실제 10%),
   FAQ 3사 수치를 **멀쩡한 값에서 틀린 값으로** 바꿔 놓았다
2. **`git checkout --` / `git stash --`로 미커밋 작업을 세 번 날렸다.** 돌연변이 복원은
   **python 역치환 + md5 대조**로, 그리고 **치환문이 유일한지 쓰기 전에** 확인할 것
3. **배포 대기 sentinel을 세 번 잘못 골랐다** — 이미 참인 값으로 걸어 즉시 통과했다.
   **옛값의 부재**로 걸 것
4. **소스를 세어 결론냈다** — 분량·개수는 렌더 결과로
5. **필드 이름을 믿었다** — `bigImageUrl`은 URL이 아니라 **파일명**이다
6. **"의심 세 건"으로 시작했다** — 전수 대조가 15건을 찾았다. 눈으로 고른 셋은 그중 셋일 뿐
7. **체크리스트가 소스 문자열을 봤다** — 조건부 블록 안의 문자열은 조건을 꺼도 남는다.
   **라이브 결과로** 판정할 것. (`grep -c`는 0건일 때 exit 1이라는 것도 같이 밟았다)
